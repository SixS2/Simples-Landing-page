## Descrição do caso escolhido
O projeto consiste em um site para uma agência de web design e desenvolvimento (profissionais autônomos) liderada por Saniel e Paulo. A iniciativa visa oferecer soluções digitais para empresas.

## Necessidade identificada
O problema principal era a ausência de um canal próprio para divulgar os serviços prestados, o que dificultava a captação de clientes e o recebimento de orçamentos de forma centralizada.

## Público-alvo
Empresas de pequeno e médio porte que precisam modernizar ou iniciar sua presença digital. Esse público precisa encontrar rapidamente os tipos de serviços oferecidos (institucional, e-commerce, landing page) e uma forma rápida de contato.

## Objetivo do site
A principal ação esperada do visitante é clicar no botão do WhatsApp para solicitar um orçamento.

## Processo de desenvolvimento
Iniciamos com o diagnóstico da necessidade do nosso próprio serviço. Em seguida, estruturamos o HTML focando na clareza do conteúdo e no botão de chamada para ação. O CSS foi pensado com uma paleta de cores pastéis mais escuras para dar um tom profissional e sério. Por fim, aplicamos o JavaScript e as classes do Bootstrap.

## Principais decisões do projeto
- **Estrutura HTML:** Utilizamos tags semânticas (`<header>`, `<main>`, `<section>`) para boa indexação.
- **Visual:** Cores escuras e contrastantes (fundo azul petróleo, texto claro) para boa legibilidade e acessibilidade.
- **Responsividade:** Aplicamos Media Queries no CSS para garantir que a página fique bem ajustada em smartphones.

## Funcionalidade em JavaScript
Implementamos um sistema de "Expandir e Recolher" (Accordion) na seção de "Dúvidas Frequentes". Ele funciona escutando o clique nos botões e alterando o estilo `display` (`block`/`none`) do parágrafo logo abaixo. Foi escolhido para evitar muita poluição visual na tela, mostrando os textos apenas quando o usuário deseja ler.

## Uso de Bootstrap
Utilizamos o Bootstrap de forma introdutória focando nas classes utilitárias de botões (`btn`, `btn-success`, `btn-dark`, `btn-lg`, `w-100`) para padronizar rapidamente as chamadas de ação da interface sem precisarmos escrever regras complexas de CSS para estados de 'hover' ou bordas.

## Testes realizados
Testamos a visualização no computador e reduzimos a janela do navegador para verificar a responsividade em tamanhos de tela mobile. O JavaScript foi testado clicando múltiplas vezes nos botões de FAQ. A acessibilidade foi checada garantindo alto contraste entre fundo escuro e letras claras.
